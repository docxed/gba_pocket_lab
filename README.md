# Poké Lab v0.33

Poké Lab is a browser-based tool for adding a Start menu cheat option to supported GBA Pokémon ROM hacks. It also includes tools for money cheats, shop cheats, and item lookup.

To patch SoulGold MegaXtream vTH.1.1.4-4, select **Pokémon SoulGold MegaXtream**, load your local `.gba` file, and choose **Patch & download**. Open the downloaded ROM and choose **Start > Cheat**.
