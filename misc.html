RAM Finder

Load two RAM dumps and enter the balance from each. Add a third dump to narrow the results.

How to save a RAM dump in mGBA

Tools → Memory Viewer → Save memory range. Set bank = -1, Start Address = 0x02000000, Byte Count = 0x40000. Uncheck Dump across banks. Save before.bin, buy something, record the new balance and save after.bin. If needed, try IWRAM: Start Address 0x03000000, Byte Count 0x8000. Do not use .sav files.
